# Chamber sources: drafts, their flaws, and their fixes

Each folder is one chamber as it came out of design: a generator, the
first draft (`flawed.txt`, with its intended solution), the cheese scripts
a shortcut hunter proved on it (`cheese-*.txt`: the same chamber with the
cheese as its solution), and the fixed version (`fixed*.txt`). They are the
material for review rounds in a story: GLaDOS's flawed draft, the flaw
you find, her patch.
